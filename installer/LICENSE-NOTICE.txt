WispWasp - please read before installing

WHAT THIS IS
WispWasp listens to audio from your PC, transcribes it, turns what it heard
into an image prompt, and can publish generated images to a local page for
OBS.

WHAT IS NOT INCLUDED
The installer contains the WispWasp application. ComfyUI, its Python/PyTorch
environment, and image models are downloaded separately when local generation
is selected. They are large and remain separate projects with their own
licenses.

If you already have a compatible ComfyUI installation, WispWasp can use it
instead of downloading another copy.

WHAT YOU NEED FOR LOCAL GENERATION
  - Windows 10 or 11, 64-bit
  - A supported NVIDIA GPU
  - Enough disk space for ComfyUI and the model you choose

The online image backend does not require ComfyUI or a local image model.

IF SOMETHING GOES WRONG
Run WispWasp.exe with --selftest. It checks the packaged application and
writes a report to %USERPROFILE%\WispWasp\selftest.log.

UNSIGNED BUILD
This build is not code signed. Windows may show a SmartScreen warning because
the executable does not have an established signing reputation. Only install
a build obtained from a source you trust.

PRIVACY AND NETWORK USE
Local audio capture and transcription run on the machine.

When the local ComfyUI backend is used, image prompts are sent to the local
ComfyUI service.

When the Pollinations backend is selected, WispWasp sends the image prompt
and generation request to that external service. WispWasp does not send the
recorded audio clip to Pollinations.

WispWasp can also contact GitHub, Hugging Face, and Civitai for update checks,
setup downloads, model metadata, and model downloads when those features are
used. Those services have their own terms and privacy policies.

WHERE YOUR FILES GO
  Settings and overlay images:  %LOCALAPPDATA%\WispWasp
  Crash/self-test logs:         %USERPROFILE%\WispWasp

Uninstalling the program does not intentionally delete your settings or
generated images.
